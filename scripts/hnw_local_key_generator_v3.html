HNW Offline Key Pair Generator

MANDATORY: Run only on the permanently air-gapped machine. Never copy the private key to an online system.

Generates an RSA-OAEP / SHA-256 3072-bit key pair for the TOHONESTY-INTAKE-V1 hybrid encryption protocol. The public output is wrapped in the exact JSON format expected by the website. The private key remains a JWK and must stay offline.

Use a unique Key ID whenever you replace a key within the same month.
